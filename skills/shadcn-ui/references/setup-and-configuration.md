# Setup and Configuration

## Initialize New Project

```bash
# Create new Next.js project
npx create-next-app@latest my-app --typescript --tailwind --eslint --app
cd my-app
npx shadcn@latest init
```

## Initialize Existing Project

```bash
# Install required dependencies
npm install tailwindcss-animate class-variance-authority clsx tailwind-merge lucide-react

# Initialize shadcn/ui
npx shadcn@latest init

# Install commonly used components
npx shadcn@latest add button input form card dialog select toast
```

## Configuration Files

### tsconfig.json

Ensure path alias is configured:

```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

## Registry Security

Components from `npx shadcn@latest add` are fetched remotely. Always:
- Verify the registry source is trusted before installation
- Review generated code before production use
- Only install components from trusted registries

## Dependencies

Required packages (installed automatically by `shadcn init`):
- `tailwindcss-animate` - Animation utilities
- `class-variance-authority` - Variant handling
- `clsx` - Conditional classes
- `tailwind-merge` - Merge Tailwind classes
- `lucide-react` - Icon library
- `@radix-ui/*` - Primitive components (installed per component)
